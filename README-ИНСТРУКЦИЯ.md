# Практическое занятие №13. Тестирование проекта

Решение выполнено в **Visual Studio 2019**, консольное приложение **«Консольное приложение (.NET Framework)», .NET Framework 4.7.2**.

В **одном консольном проекте** (`PracticalWork13`) реализованы все три варианта информационных систем:

| Вариант | Система | Пространство имён |
|---------|---------|-------------------|
| 1 | Учет товаров на складе | `PracticalWork13.Warehouse` |
| 2 | Учет заказов интернет-магазина | `PracticalWork13.Orders` |
| 3 | Автоматизация работы учебной части (деканат) | `PracticalWork13.University` |

К каждому варианту — отдельный **NUnit-тестовый проект**:

| Тест-проект | Проверяет | Тестов |
|-------------|-----------|--------|
| `WarehouseTests` | Вариант 1 (склад) | 14 |
| `OrderTests` | Вариант 2 (заказы) | 10 |
| `UniversityTests` | Вариант 3 (деканат) | 6 |

**Всего: 30 автоматических тестов (NUnit 3.13.3).**

---

## 1. Требования

- Visual Studio 2019 (любая редакция, включая Community);
- .NET Framework 4.7.2 Developer Pack / Targeting Pack;
- доступ в интернет для восстановления NuGet-пакетов (NUnit, адаптер, Test SDK).

## 2. Как открыть решение

1. Распакуйте архив `PracticalWork13.zip` в удобную папку, например `C:\Practic\`.
2. Откройте файл **`PracticalWork13.sln`** двойным щелчком (либо VS 2019 → *Файл → Открыть → Проект/Решение*).
3. Дождитесь загрузки решения. VS автоматически восстановит NuGet-пакеты
   тестовых проектов. Если восстановление не запустилось:
   *ПКМ по решению → Restore NuGet Packages* (или *Восстановить пакеты NuGet*).

## 3. Как запустить приложение

1. В обозревателе решений убедитесь, что запускаемым проектом назначен
   **PracticalWork13** (ПКМ по проекту → *Set as StartUp Project* / *Назначить запускаемым проектом*).
2. Нажмите **F5** (с отладкой) или **Ctrl+F5** (без отладки).
3. В консоли откроется главное меню:

   ```
   1 - Вариант 1. Учет товаров на складе
   2 - Вариант 2. Учет заказов интернет-магазина
   3 - Вариант 3. Автоматизация работы деканата
   0 - Выход
   ```

### Демо-сценарии

**Вариант 1 (склад).** Авторизация: кладовщик `store / 12345`, администратор `admin / admin123`.
Добавьте товар (попробуйте ввести цену `abc` или `-500` — увидите сообщение
«Неверный формат цены»), выполните поиск по артикулу `NB-001`, оформите
приход/расход и сформируйте отчет по остаткам.

**Вариант 2 (заказы).** Зарегистрируйте клиента (email, пароль ≥ 6 символов, телефон),
добавьте в корзину товаров на сумму от 5000 руб. — при оформлении заказа
скидка 5% применится автоматически. Смена статуса заказа доступна только
администратору (ответ `y` на вопрос «Вы администратор?»).

**Вариант 3 (деканат).** Создайте группу, добавьте студента, проставьте оценки
(попробуйте поставить `6` — увидите «Оценка должна быть в диапазоне от 2 до 5»),
затем посмотрите средний балл (для оценок 4, 5, 4 — 4.33).

## 4. Как запустить тесты (NUnit)

1. В меню VS: **Тест (Test) → Обозреватель тестов (Test Explorer)**.
2. Дождитесь обнаружения тестов (выполняется сборка проектов).
3. Нажмите **«Запустить все» (Run All)** — зелёным цветом будут отмечены
   пройденные тесты. Ожидается: **30 пройдено / 0 не пройдено**.

Имена тестов соответствуют ID тест-кейсов из задания:
`TC_SK_01…` (склад), `TC_OR_01…` (заказы), `TC_UN_01…` (деканат).
